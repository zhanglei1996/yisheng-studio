# 译声工坊 V1 产品需求文档

## 产品目标

译声工坊是一款面向程序员和知识学习者的本地 AI 视频中文化桌面工具。用户导入拥有合法使用权的英文视频，应用在本地完成媒体处理、语音识别、任务管理和导出，并直接调用用户配置的翻译与语音服务。

V1 的核心承诺是：一段 10～30 分钟的单人英文技术视频，无需人工逐句处理，即可得到术语基本准确、时间轴可控、可局部修正的中文配音版本。

## 目标用户

- 经常观看英文技术课程、访谈与演讲的程序员和知识学习者。
- 在意原始文件隐私，希望自行选择模型服务商并承担费用的用户。
- 需要校对专业术语、双语字幕和指定片段重生成的内容创作者。

## V1 范围

- macOS 13+，Apple Silicon 与 Intel 通用包。
- 本地导入 MP4、MOV、MKV 等视频；英文转简体中文。
- whisper.cpp 本地识别，OpenAI 兼容翻译服务，系统/讯飞/腾讯 TTS。
- 快速生成与先校对两种工作流。
- 全局术语库、项目术语覆盖、字幕译文与配音文案分离。
- 受约束时间轴、局部重生成、普通混音与高质量人声分离。
- 导出中文配音 MP4、中文/英文 SRT、双语 ASS 与中文 WAV。

不包含视频平台下载、账号与云同步、多人协作、声音克隆、口型同步、多人说话人配音、Windows/Linux 和完全离线翻译。

## 核心流程

1. 首次启动确认隐私与版权边界，检测并下载本地组件。
2. 从项目库导入视频，选择生成模式、服务商、声音与原声处理方式。
3. 完成媒体检查、代理生成、音频提取、识别和术语确认。
4. 翻译后按模式自动配音或等待人工校对。
5. 完成时长适配、混音、字幕与预览。
6. 用户可修改任意片段，只重新运行受影响的下游阶段。
7. 导出完整结果包到用户选择的目录。

## 成功指标

- 10～30 分钟样例视频可在无逐句操作的情况下跑通完整链路。
- 编辑单个片段不会重新执行无关上游阶段。
- 片段音频不重叠；无法自动适配的片段有明确风险提示。
- 应用重启后可从最近完成的检查点恢复。
- API Key 不出现在 SQLite、普通配置、日志、错误或诊断包中。
