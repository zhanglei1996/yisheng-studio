# 隐私、数据发送与版权边界

## 默认本地数据

原始视频、代理视频、识别结果、术语表、任务状态、中间音频和导出结果保存在用户电脑。开发者不建设视频上传、文件存储、转码或模型代理服务。

## 第三方发送范围

- 本地 whisper.cpp：不发送数据。
- 翻译 Provider：仅发送用户确认范围内的字幕文本、上下文和术语规则。
- 在线 TTS：仅发送中文配音文案与声音参数。
- macOS 系统语音：不发送数据。

每次调用前，界面显示平台名称、模型和数据类型。默认关闭遥测；诊断包必须排除凭据、字幕正文、音频、完整路径和文件名。

## 凭据

凭据保存在 macOS Keychain。SQLite 仅保存 `credential_ref`，日志和错误统一脱敏。用户可测试连接、修改配置或一键删除全部凭据。

## 内容权利

应用只导入用户自己拥有或已获授权的本地文件，不提供视频平台抓取功能。创建项目时用户需要确认拥有下载、翻译和生成衍生版本的权利。结果默认用于个人学习，产品不提供公开发布能力。
