# 第三方组件许可证发布门禁

| 组件 | 预期用途 | 发布要求 |
|---|---|---|
| Tauri 2 | 桌面运行时 | 固定版本并保留 NOTICE |
| FFmpeg | 媒体探测、混音、导出 | 使用 LGPL 构建；禁用 GPL 编码器；记录构建参数与源码地址 |
| whisper.cpp | 本地 ASR | 固定提交/版本；保留许可证与模型来源 |
| Whisper 模型 | 英文识别 | 记录下载来源、哈希、大小和许可证 |
| HT-Demucs ONNX | 人声分离 | 模型与推理依赖分别审计；任一不通过则阻断发布 |
| Phosphor Icons | UI 图标 | 固定版本并保留许可证 |

任何按需下载的运行时都必须进入带 SHA-256、Ed25519 签名、架构、最小系统版本和许可证字段的清单。
