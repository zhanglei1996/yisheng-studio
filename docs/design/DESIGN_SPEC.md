# 暗黑编辑器设计规范

视觉基准为 `docs/design/references/editor-dark-reference.png`。整体采用专业剪辑工具的紧凑密度：左侧模块导航、中央视频检查、右侧片段属性、底部大比例时间轴。

## Token

- 背景 `#0B0D10`
- 面板 `#12161B`
- 浮层 `#171C22`
- 边框 `#2A3038`
- 主文字 `#F3F5F7`
- 次文字 `#9CA3AF`
- 蓝色 `#2F7DFF`
- 警告 `#F5A524`
- 完成 `#31C48D`
- 错误 `#F05252`
- 圆角 6px；间距以 4px 为基准；时间码使用 SF Mono。

## 编辑器比例

- 顶栏 52px，左导航 202px，右检查器 420～500px。
- 预览/属性区约占可用高度 48%，时间轴占 52%。
- 时间轴轨道标签 188px，轨道内容支持水平缩放和滚动。
- 最小窗口 1180×720；1440×900 以上显示完整布局。

## 交互颜色

- 蓝色：选中、当前播放头、运行中。
- 绿色：完成和可用。
- 琥珀：需要人工处理但不阻断其他片段。
- 红色：阻断任务或导出。

图标使用 Phosphor Icons，不用字符或手绘 SVG 代替。纯图标按钮提供 `title` 和 `aria-label`。

## 基础组件

- 通用弹窗、按钮、输入框、文本域、选择器、复选/单选、分段选择器、开关、滑杆、进度条、Tooltip 与危险操作确认统一使用 Ant Design 暗色主题，并通过全局 Token 映射现有视觉规范。
- 时间轴片段、波形和视频预览保留领域定制组件，避免组件库限制剪辑交互；播放、工具按钮和缩放滑杆使用 Ant Design 承载通用交互状态。
- macOS 三色窗口按钮属于系统标题栏，不在 HTML 中绘制；Tauri 使用原生窗口装饰和 Overlay 标题栏，并以 `x: 13, y: 17` 对齐 52px 顶栏中心。
- 导出只保留编辑器项目级入口。输出目录使用单一组合输入容器，路径和文件夹按钮不得拼接成两个独立边框。
